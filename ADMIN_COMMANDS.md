# Команды администратора — Мишка Макс support bot

Все команды пишутся прямо в чате поддержки (где бот принимает тикеты от пользователей).

---

## Ответ на тикет

### Swipe-reply (самый быстрый способ)
Свайпните/ответьте на карточку тикета или на уведомление «Новое сообщение от...» прямо в MAX (как в обычном мессенджере) и напишите текст. Бот сам найдёт нужный тикет по сообщению, на которое вы ответили, отправит текст пользователю и закроет тикет. Команда не нужна.

Если тикет уже закрыт, но нужно дослать ещё файл/сообщение — свайпните то же сообщение ещё раз, тикет повторно не закроется.

### Кнопки на карточке тикета
- **[Вариант 1/2/3]** — отправить готовый вариант ответа от ИИ, тикет закрывается автоматически
- **[✍️ Свой ответ]** — войти в режим свободного ответа (см. `/startreply`)
- **[✅ Решён]** / **[✗ Не решён]** — закрыть или вернуть тикет в очередь без отправки сообщения пользователю

### `/startreply {id}`
Активирует режим свободного ответа для тикета — по кнопке или без неё, если карточку найти неудобно. Работает и на уже закрытых тикетах.

Дальше отправляйте текст и файлы **по одному сообщению** — каждое уходит пользователю сразу. Когда закончили — напишите `/done`.

### `/done`
Завершает режим свободного ответа (начатый через `/startreply` или `[✍️ Свой ответ]`), закрывает тикет и отправляет пользователю запрос оценки.

### `/reply {id} {текст}`
Отправить ответ одной командой и сразу закрыть тикет. Файлы так не отправить — только текст.
```
/reply 239 Здравствуйте! Сейчас разберёмся с вашим вопросом.
```

### `/message {id} {текст}`
Отправить сообщение пользователю **независимо от статуса тикета** — работает даже на уже закрытом. Тикет не закрывает и не открывает повторно.
```
/message 580 Ещё раз спасибо за обращение!
```

### `/send {user_id} {текст}`
То же самое, но по id пользователя, а не по номеру тикета — только если у него есть **открытый** тикет.
```
/send 123456789 Проверьте, пожалуйста, папку Спам
```

## Поиск и список тикетов

### `/queue`
Список всех открытых тикетов: номер, метка приоритета, проект, пользователь, его id, начало вопроса, время ожидания.

### `/find {имя или @username}`
Поиск пользователя по всей истории обращений (включая закрытые) — помогает найти `user_id` для `/send`, `/block` и т.д.
```
/find Ольга
/find @ivan_petrov
```

## База знаний (ответы для ИИ)

ИИ формирует варианты ответов на основе этой базы. Редактировать можно прямо из чата, без захода в базу данных.

### `/kb add {тема}`
Начать новую запись. Дальше пришлите текст ответа **следующим сообщением** — бот прогонит его через ИИ (поправит грамматику и тон, факты и ссылки не тронет) и покажет на подтверждение:
- **[✅ Сохранить отредактированный]** — сохранить вариант от ИИ
- **[📝 Оставить как написал(а)]** — сохранить ваш исходный текст без правок
- **[✏️ Написать заново]** — вернуться к вводу текста
- **[❌ Отмена]** — отменить добавление

```
/kb add Как вернуть деньги за покупку
```

### `/kb edit {id}`
То же самое, но редактирует существующую запись (бот покажет текущий текст перед вводом нового).

### `/kb list`
Список всех тем с номерами.

### `/kb show {id}`
Полный текст одной записи.

### `/kb delete {id}`
Удалить запись.

## Пользователи

### `/block {user_id} [причина]`
Заблокировать пользователя — его сообщения перестают создавать тикеты и обрабатываться ботом полностью (молча).
```
/block 123456789 спамит рекламой
```

### `/unblock {user_id}`
Снять блокировку.

---

## Режим отсутствия

### `/pause {время}`
Включить режим «мы временно недоступны» — новые тикеты не создаются, пользователь видит сообщение об этом.
```
/pause 2h     — на 2 часа
/pause 30m    — на 30 минут
/pause 1d     — на 1 день
/pause        — без ограничения по времени
```

### `/open`
Выключить режим отсутствия, снова принимать обращения.

## Шпаргалка

| Команда | Что делает |
|---|---|
| swipe-reply | Ответить на тикет, свайпнув сообщение |
| `/startreply {id}` | Войти в режим ответа (текст + файлы, несколько сообщений) |
| `/done` | Завершить режим ответа, закрыть тикет |
| `/reply {id} {текст}` | Ответить и закрыть тикет одной командой |
| `/message {id} {текст}` | Написать по тикету любого статуса |
| `/send {user_id} {текст}` | Написать по id пользователя (нужен открытый тикет) |
| `/queue` | Список открытых тикетов |
| `/find {имя}` | Найти user_id по истории обращений |
| `/kb add {тема}` | Добавить ответ в базу знаний |
| `/kb edit {id}` | Отредактировать ответ |
| `/kb list` / `/kb show {id}` | Посмотреть базу знаний |
| `/kb delete {id}` | Удалить ответ из базы |
| `/block {user_id}` / `/unblock {user_id}` | Заблокировать / разблокировать пользователя |
| `/pause {время}` / `/open` | Режим отсутствия вкл/выкл |
